1. Quick start

  1. Select Import / choose CC model → Uniform distribution for the baseline paper model. Human and mouse distributions are different models and should not be used for the paper examples below.
  2. Choose Calculate pressure (IOP) and enter a known Flowrate, or choose Calculate flowrate and enter a known Pressure / IOP. Only the required input is displayed.
  3. Open Advanced settings → Constants to set Pev, Rtm and other parameters. Rtm is a model input. Automatic Rtm calibration is currently disabled.
  4. Set all three Additional Procedure selectors to None for an intact eye, or configure the desired procedure.
  5. Click Solve. Select a plot and inspect the rings. After changing any calculation input, click Solve again; the existing result may otherwise describe the previous setup.
Fresh baseline: start from a freshly opened calculator, select Uniform, and check Constants. Clear every field in Segment Profiles and Manual CC distribution when reproducing a uniform baseline. Choosing Uniform alone does not necessarily reset all other inputs.

With default settings (Pev = 8, Rtm = 2, Flowrate = 2, no procedures), IOP is approximately 15.09 mmHg. Changing the calculation mode should preserve the same physical parameters; pressure and flow should then describe the same operating point.

2. Parameters and defaults

TM means trabecular meshwork and its modeled inner-wall resistance; SC means Schlemm’s canal; CC means collector channels and the downstream resistance represented by them. Defaults are starting settings, not a guarantee that every imported model uses these values.

What does “Rcc override” do?

Leave it blank for the baseline pressure-dependent model. Entering 1.5 fixes the total equivalent CC resistance at 1.5 mmHg·min/μL. It does not assign 1.5 to each channel. In the current code the default law uses IOP: 1.8 at IOP ≤ 7, 2.033 − 0.033 × IOP between 7 and 25, and 1.2 at IOP ≥ 25 mmHg. The piecewise values are rounded model constants. Keep this field blank for Figures 4 and 5.

Why both Qu and a checkbox?

The checkbox selects whether the pathway is present; Qu sets its magnitude. With Qu = 0.28, unchecked means no unconventional flow, while checked includes 0.28 μL/min. In Calculate pressure mode, conventional flow is the entered flowrate minus Qu; choose an input larger than Qu. In Calculate flowrate mode, the reported total includes Qu.

3. Profiles, arrays and overrides

All fields below are in Advanced settings → Segment Profiles and are blank by default. Node indices start at 0; profile sector numbers start at 1. With N = 30 and M = 40, valid nodes are 0–1199.

FieldMeaning and example
TM resistance profile12 clock-hour sector resistances in mmHg·min/μL. Enter one value to repeat it or 12 comma-separated values. Uniform 24 is equivalent to overall Rtm = 2 because 12 sectors are in parallel. Keyed format requires all sectors, e.g. 1:24, 2:24, …, 12:24; replace the ellipsis with actual entries.
TM full node arrayLocal TM resistor values, not sector or whole-eye values. Enter one value or exactly N × M values. Uniform 2400 is equivalent to overall Rtm = 2 for 1,200 nodes.
SC baseline height profileUndeformed heights in μm for N equal circumferential sectors. Enter one value or N values. Uniform 20 preserves the baseline h0.
SC full node arrayUndeformed height at every node in μm. Enter one value or N × M values. These are h0 values, not final computed heights and not SC resistances.
TM node resistance overridesReplace only named local resistors, e.g. 120:2400, 121-140:3200. Unspecified nodes retain their underlying values.
SC node height overridesReplace only named initial heights, e.g. 120:20, 121-140:14. The solver still calculates final deformed height.
SC conductance multiplierDimensionless scaling of circumferential SC links. Blank means 1. Example 120-140:0.5 halves conductance (doubles resistance) in those links. Accepts one value, N × M values, or selected ranges. This is an additional modeling control, not a parameter needed for the baseline paper reproduction.
SC conductance overrideDirect replacement conductance in μL/min/mmHg; e.g. 120:0 blocks that link. Blank retains calculated conductance. A specified value takes precedence over the height-based conductance and multiplier for that link.

Priority: a full node array takes precedence over a profile; a profile takes precedence over scalar Rtm or h0. Selected node overrides are then applied on top. Profile values must cover all sectors; use node overrides for sparse changes. A single number in a full-array field repeats uniformly.

Different resistance scales: with 1,200 nodes, Rtm = 2 → each node resistor is 2 × 1,200 = 2,400. Each 100-node clock-hour sector has equivalent resistance 2,400/100 = 24. Thus entering 2 into a TM node array does not reproduce whole-eye Rtm = 2.

SC segment i is the link from node i to node i+1, wrapping at the end of the ring. Conductance multipliers change SC links, not TM resistors or CCs. Clear all conductance controls for the baseline model.

4. Procedures and node positions

Use Additional Procedure for up to three procedures. Choose None for unused slots. Explicit locations use node indices, not degrees or clock-hour labels. By default each node step is 360/1200 = 0.3°, so approximately 100 nodes span one clock hour (30°). Enter ranges in ascending order, within the node limits; use separate ranges when crossing node zero.

Trabeculotomy

  1. Select Trabeculotomy.
  2. Enter Position ranges, e.g. 0-99 or 0-99, 300-399. Endpoints are included. Alternatively leave ranges blank and select a preset.
  3. Click Solve. In Calculate pressure mode inspect IOP; in Calculate flowrate mode inspect flowrate.
Preset (only if ranges are blank)Actual baseline node ranges
1550–650: approximately one clock hour
4100–200, 400–500, 700–800, 1000–1100: four separate approximately one-hour regions, not one continuous four-hour region
120–1199: full circumference

These presets are defined for the default 1,200-node grid. If N or M changes, use explicit valid ranges rather than assuming the presets rescale. Explicit ranges override the preset. Preset one-hour ranges contain 101 nodes; 0-99 contains 100, so tiny differences are expected.

Why might a changed location give the same result? In a uniform CC model, translating the same operation by a whole CC interval can leave overall resistance unchanged. At fixed IOP, the output that changes is flowrate, not IOP. Increase the operated extent to test a different intervention, clear conflicting explicit ranges, and press Solve.

Other procedures

Sinusotomy: specify outer-wall opening ranges, e.g. 120-180. YAG holes: specify nodes, e.g. 0, 200, 400, or leave blank to use the count preset. iStent: specify starting nodes; each receives the same Stent Editor configuration. Blank places one at node 0.

Laser damage — TM only: disables TM inflow at the selected start node and node count. Laser damage — full node: additionally disconnects neighboring SC links and any CC at those nodes. These are deliberate model interventions, not substitutes for trabeculotomy.

Collector channels

Use Import / choose CC model for Uniform, Default human eye (29 channels), Default mouse eye (34 channels), or a saved JSON file. To enter a custom layout, use Advanced → Collector Channels → Manual CC distribution, e.g. 0:1, 40:1, 80:0.5. This defines the specified CC list; it does not merely edit three channels of the original list. The number after the colon scales that channel’s conductance; a node alone defaults to 1. Blank uses the uniform layout from N and M.

5. Stent Editor

  1. Select iStent in a procedure slot and enter implantation start nodes, e.g. 0 or 0, 300.
  2. Open Advanced settings → Stent Editor. Enter geometry and inlet properties. All stents currently use this shared configuration.
  3. Close Advanced settings and click Solve. The name is descriptive only; it does not load a device preset.
FieldDefault and interpretation
NameCustom iStent; label only.
Length / Inlet offset1000 / 0 μm. Offset is measured from the configured stent start; keep it within the stent length.
Width / Height120 / 60 μm; internal channel dimensions for the simple, windowless model.
Before / After dilation nodes0 / 0. Number of extra dilated nodes before/after the stent, not μm. Default grid spacing is 30 μm per node.
After heightBlank: uses channel height, or spine height for a windowed stent. Sets height in extra dilation nodes; changing it alone adds no dilation nodes.
Inlet conductance (G_inlet)0 μL/min/mmHg, a special setting for an ideal zero-resistance inlet. Positive values specify finite conductance. Zero does not mean blocked.
Stent geometrySame as solver; alternatively ellipse or rectangle.
Two-way inletChecked. Allows propagation on both sides of an end inlet; most relevant when the inlet is at an end.
Number of windows0. For a windowed stent, also specify window length/height and spine length/height, all in μm. They are blank initially.
Qinlet or G_inlet? The original Northwestern editor labels the parameter G_inlet: inlet conductance in μL/min/mmHg, not a prescribed flowrate. Here it is “Inlet conductance.” For a finite inlet, Q_inlet = G_inlet × (IOP − inlet pressure). The original custom-stent form starts at G_inlet = 50; our editor starts at 0. Match values explicitly when comparing versions.

Illustrative iStent inject configuration

Set length 230 μm, inlet offset 115 μm, width 50 μm, height 50 μm, after height 150 μm, inlet conductance 42.15 μL/min/mmHg, Two-way checked, ellipse geometry, and Number of windows 0. Before/after dilation counts remain separate controls; set them explicitly if your experiment includes dilation. Dimensions and offsets are discretized to the SC grid, so they need not be exact multiples of a node spacing but are rounded down internally.

Changing type: the original website provides generic windowed/windowless × bidirectional/unidirectional presets. This calculator currently uses manual configuration instead of a device-type menu. Editing Name alone changes no physics. Match geometry, inlet conductance, dilation, and beta when comparing stents; the generic defaults are not a validated preset for every named device.

6. Results and saved models

IOP is absolute pressure in mmHg. Flow rate is μL/min. With unconventional flow off, Resistance = (IOP − Pev)/Q in mmHg·min/μL, and Facility is its reciprocal. With unconventional flow enabled, the reported equivalent resistance/facility also accounts for the separate unconventional pathway; do not use the simple formula for total flow unchanged.

Setup Ring previews the current setup. Solution Ring and Profiles show the last solved result. Choose Pressure distribution, Canal height, or Collector channel flow. Canal height is in μm, not mmHg, and differs from h0. Hover the pressure ring to read local pressure and height, or a CC to read flow. Click a ring to enlarge it.

Click Export model + results (JSON) after Solve to save inputs and calculated series. If inputs were edited after the last solve, exported inputs and results can describe different states; always solve immediately before export. Reopen via Import / choose CC model → Choose your own file. Send this JSON plus a screenshot when reporting a discrepancy.

7. Reproduce Figure 4: normalized resistance

Figure 4 compares flow resistance versus IOP for enucleated human eyes. Its model line is R/R10, where R10 is resistance at IOP = 10 mmHg. It is not Rtm, raw Resistance, or resistance divided by the first row unless the first row is at 10 mmHg.

  1. Start a clean Uniform model with no procedures and blank profile, array, node override, SC conductance and manual CC fields.
  2. In Constants set Pev = 0, Rtm = 2, Etm = 13, h0 = 20, hs = 3, N = 30, M = 40. Leave Rcc override and beta blank; keep unconventional flow unchecked. Default max error = 0.0001 is adequate for the displayed precision.
  3. Select Calculate flowrate. Enter IOP = 5, 10, 15, 20, 25, 30, 40, 45 and 50 mmHg in turn, clicking Solve and recording Q and Resistance each time.
  4. Divide every Resistance by the value at IOP = 10, approximately 3.7196. Plot IOP on the x-axis and R/R10 on the y-axis.

8. Reproduce Figure 5: canal height

Use the same clean baseline settings as Figure 4, including Pev = 0 and Rtm = 2. Select Calculate flowrate and solve at IOP = 5, 15 and 30 mmHg. Select Canal height under Plot.

The website plots μm around the full eye. The paper plots h/h0 over one CC interval. Export JSON and select the first 41 height values (nodes 0 through 40, inclusive). Plot x/Xcc = node index/40 and h/h0 = height/20. Other intervals repeat in this uniform baseline.

Additional Pev = 8 check (not Figure 5’s conditions)

With all other baseline parameters unchanged, select Calculate pressure, set Flowrate = 10 and Pev = 8. Expected IOP is approximately 60.187 mmHg and height approximately 1.951–2.803 μm. An older height-display bug produced a maximum near 11.45 μm while leaving IOP unchanged. That conversion bug is fixed; force-refresh if you still see the old curve.

9. Questions and troubleshooting

Why do pressure and flow fail to match when switching modes?
Keep Rtm, Pev, CC layout, geometry, procedures and all overrides identical. Automatic Rtm calibration is disabled. For example, with Pev = 0 and Rtm = 2, Flowrate = 5 gives IOP ≈ 19.698; entering that pressure returns flow ≈ 5. Comparing a model with Rtm = 5.2477 to one with Rtm = 2 compares different eyes.
Does the Rtm field show total network resistance?
No. Rtm is TM resistance only. Reported Resistance includes the modeled SC and downstream CC contributions and can vary with pressure even while Rtm stays fixed.
Why is an input ignored or disabled?
The selected calculation uses either pressure or flow as its known value. Spatial TM inputs override scalar Rtm; SC profiles/arrays override scalar h0. Explicit procedure ranges override presets. Unchecked unconventional flow ignores Qu. Check for nonblank advanced fields left from an earlier experiment.
Why does changing a procedure or editor field appear to do nothing?
Press Solve. Ensure the procedure is selected, explicit ranges are not overriding the preset, and you are looking at the calculated output rather than the fixed input. A stent name is only a label; extra dilation height is used only when extra dilation nodes exist. Uniform geometry can make translated interventions equivalent.
Can I enter arbitrary ETM, hs, h0, or conductance values?
These are coupled physical parameters; editable does not mean independently validated. Extreme settings, disconnected pathways or conflicting interventions can produce invalid or poorly converged results. Begin with the baseline, change one physical assumption at a time, and retain the exported setup.
How do I know I have the latest website?
Reopen the calculator and force-refresh (Ctrl+Shift+R on Windows; Command+Shift+R on macOS). When using the Visible OCT embed, open the standalone calculator if necessary. Report the URL, all settings and a freshly solved JSON export if results still differ.
