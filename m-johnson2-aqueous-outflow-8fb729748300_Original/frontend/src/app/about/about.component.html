About

This web application can be used to simulate how intraocular pressure (IOP) and aqueous humor outflow rate change under various conditions and surgical procedures. The application makes calculations using the same model used in our paper "Modelling the Effects of Glaucoma Surgery on Intraocular Pressure".

The model was written in Python by Nicholas Farrar and Mark Johnson based on a previous model by David B Yan, Roger D Kamm and Mark Johnson.
